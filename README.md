# Photo Album
โปรเจกต์อัลบั้มรูปภาพและวิดีโอ พัฒนาด้วย Node.js และ Express สามารถอัปโหลดไฟล์สื่อ แสดงผลแบบแบ่งหน้า และลบไฟล์ได้

## วิธีการติดตั้งและเริ่มต้นใช้งาน
รันคำสั่งต่อไปนี้ใน Terminal 

```bash
# โคลนโปรเจกต์จาก GitHub Repository
git clone https://github.com/wasankds/photo-album.git
```

```bash
# เข้าไปในโฟลเดอร์โปรเจกต์และติดตั้งโมดูล (Dependencies)
cd photo-album
npm install
```

```bash
# สร้างไฟล์ .env และเขียนเนื้อหาด้านใน
echo "PORT=3000" > .env
```

```bash
 รันเว็บเซิร์ฟเวอร์
node server.js
```
